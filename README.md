# Amazon Web Application Clone 🛒

A clean, responsive Amazon front-end clone built using **HTML5, CSS3, and JavaScript (ES6)**. Designed with modular structures, clean layout components, interactive cart state handling, and real-time product filtering.

## 🌟 Key Features

- **Responsive Header & Navigation Bar:** Category selector, search bar, location pin, and user account indicators.
- **Dynamic Product Rendering:** Products generated directly from data objects without hardcoding UI structures.
- **Interactive Search Engine:** Filter listed items dynamically by product titles.
- **Shopping Cart State:** Open/Close modal dialog, real-time item count updates, and total price accumulation.
- **Modern Flexbox & Grid Styling:** Optimized layout scaling across screen resolutions.

## 🛠️ Tech Stack

- **HTML5:** Semantic markup structure.
- **CSS3:** Custom styles, CSS Variables, Flexbox, and Grid.
- **JavaScript (ES6):** Client-side DOM manipulation, state arrays, and array operations (`filter`, `find`, `forEach`).
- **FontAwesome CDN:** UI iconography.
